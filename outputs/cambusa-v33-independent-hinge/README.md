# v33: независимая модель 71T6650 и комплект узла для заказа

**Номинальная внешняя посадка пройдена по второй заводской выгрузке: 681 положение 0–170°, шаг 0,25°.** Все семь тел петли присутствуют; неожиданных пересечений с дверью, боковиной и консервативным сплошным габаритом OB-3030 нет. Минимальный измеренный зазор подвижных звеньев до дерева — **0,609 мм**. Это проверка узла при номинальной регулировке, а не выпуск всего шкафа и не физическое испытание покупного изделия.

## Какая модель найдена

У [Démos для 71T6650](https://www.demos-trade.sk/blum-71t6650-zaves-polonalozeny-skrutka-170/) опубликован [DWG](https://www.demos-trade.sk/product-file/download/33779), независимый от прежнего DXF Buller. Сохранён [исходный файл](../../inputs/supplier-cad/blum-71t6650-demos.dwg), SHA-256 `ecec7b14e4d15a160e233c4c26f5d432c24c65b932d861ef0ef3ebec0dbca055`.

Внутри — бинарные ACIS-данные, Autodesk AutoCAD / ASM 215.0.0.4214, дата источника 12.12.2012. Из DWG извлечены семь исходных бинарных потоков без округления координат и без промежуточного перевода в SAT. Обычная команда DWG→DXF для этого файла теряет часть данных; её результат в комплект не включён. [Манифест извлечения](../../inputs/supplier-cad/demos-71t6650/manifest.json).

В B-rep перенесены **все 431 исходная грань** семи тел; замкнутые тела валидны. Формы сплайнов и аналитические поверхности сохранены. Численная точность соединения границ принята **0,00001 мм**; это допуск конвертации, исходная запись `resabs=0,000001 мм` сохранена отдельно. Шесть UV-обходов на чашке исправлены с сохранением идентичности 3D-рёбер. Никакие внутренние пересечения не вырезались. [Полный протокол](../blum-independent-v33/explicit-conversion.json).

Монтажная плоскость исходного DWG наклонена к файловой оси на 0,000018724°. По нормали заводской грани выполнен **один общий жёсткий поворот всех семи тел**, без подгонки отдельных деталей. Так тыл чашки точно совпадает с монтажной плоскостью Y=−38,5. Без этого возникало паразитное пересечение 0,0033 мм³. [Матрица установки](../blum-independent-v33/canonical/alignment.json). Планка 175H7190 взята из ранее сохранённого отдельного заводского DXF; новая выгрузка относится к самой петле.

## Что выяснено о внутренних перекрытиях

Во второй выгрузке внутренние объёмы тоже перекрываются. Для пары **тел 2 и 4** происхождение проверено независимо: девять точек лежат внутри обоих тел по исходным контурам и аналитическим поверхностям. Проверка лучом не использует булевы операции и классификацию OCCT; кривые оцениваются по исходным параметрам, минимальное расстояние попаданий до границы контура — 0,090 мм. [Протокол](../blum-independent-v33/source-ray-check.json) · [воспроизводимая проверка](../../scripts/verify_blum_source_overlap.py).

**Как минимум это перекрытие находится в исходной CAD-геометрии и не вызвано прежним переносом DXF.** Следовательно, тела этой выгрузки нельзя принимать за физически непересекающиеся детали для самостоятельного изготовления петли. Причины всех остальных перекрытий по отдельности не сертифицированы. Утверждение «любые пересечения между звеньями исправлены» не делается.

Покупается целая серийная 71T6650. Для её заявленного угла используется [характеристика Blum 170°](https://publications.blum.com/2026/catalogue/en/82/); CAD проверяет внешний проход. Шестизвенный граф движения сохранён из предыдущего заводского DXF, где оси парных звеньев совпадают. Это расчётная установка новых наружных тел на этот граф, не заводская анимированная сборка и не независимое доказательство внутренней кинематики.

## Изменения деревянной детали

Прежняя выборка 9,5 × 25 × 3,2 мм давала у звена 2 всего **0,114 мм** до дерева. Для комплекта принят больший технологический запас:

| Обработка двери | v33 |
|---|---|
| Три отверстия чашек | Ø35,2 × 11,2, плоское дно |
| Центры чашек | 23 от кромки с петлями; 90 / 482 / 874 от низа |
| Три тыльные выборки, открытые в кромку | **11 × 28 × 6, R3** |
| Пилоты шурупов | Ø2,7 × 8; межосевое 45, смещение 9,5 от чашки |
| Планки на боковине | линия 26 от передней кромки; межосевое 32 |

Внешний габарит двери **452 × 964 × 18**, боковины **416 × 969 × 24**, шкафа **1000 × 1800 × 500 мм** сохранён. Под чашкой остаётся 6,8 мм фанеры, перед выборкой — 12 мм. Новая обработка не выходит на лицевую сторону. Проставок под петлю и чашку нет.

Полный расчёт дал минимумы до дерева: звено 2 — **0,917 мм**, звено 4 — **0,609 мм**, звено 3 — 2,712 мм. [681 положение и протокол зазоров](exact-fit.json). Это минимумы в отсчётах, не непрерывный сертификат между ними. Прежняя оценка прохода наружного контура двери мимо каркаса не ухудшается: материал только удалён.

Номинальные потайные шурупы 609.1500 посажены по новому CAD чашки и реальной планке: пересечений головок с металлом нет. [Посадка шурупов](../blum-independent-v33/canonical/screw-seats.json). Резьба показана номинальным объёмом.

## Что заказать

На левую дверь: **3 × 71T6650, 3 × 175H7190, 12 × 609.1500**. По просмотренным 06.11.2026 карточкам российских продавцов — **4 658,13 ₽** без доставки, дерева и обработки. Наличие и цена не зарезервированы; это ведомость, не подтверждённый счёт. Доводчик не включён.

Дерево заказывается с готовой присадкой по [ORDER-SPEC.md](ORDER-SPEC.md), шести DXF и таблице 183 операций. До запуска обработки изготовитель должен подтвердить фактические окончательные толщины, допуски и возможность обработки обеих пластей и торцов. Пакет готов для такого запроса; подтверждения изготовителя пока нет. Дома остаются PZ2, пристёгивание CLIP и регулировка; фрезеровка дома не предусмотрена.

Весь шкаф не объявлен готовым к производству: его правые механизмы и другие незакрытые пункты остаются в общем TODO. Физическая приёмка фактических деталей, вырыв шурупов в партии фанеры и крайние сочетания регулировок этим расчётом не заменены.

## Пересборка

Из корня репозитория, в окружении зависимостей проекта:

```sh
python scripts/extract_blum_dwg.py
python scripts/convert_independent_blum.py
python scripts/align_independent_blum.py
python scripts/seat_blum_screws.py --cad-dir outputs/blum-independent-v33/canonical
python scripts/verify_blum_source_overlap.py
python scripts/check_independent_blum_node.py
python scripts/build_independent_blum_node.py
python scripts/export_independent_blum_machining.py
```

После проверки просмотрщика запустить `python scripts/package_independent_blum_node.py`. Для сравнения плотностей дискретизации в репозитории сохранён отдельный протокол на 1025 точках кривой; текущая проверка использует 4097.

Нужны GNU LibreDWG 0.14, `requirements-cad.txt` и основные зависимости геометрии проекта. Параметры выборки находятся в `scripts/blum_node_v33_spec.py`. Старые v31 и v32 сохранены отдельными тегами.
