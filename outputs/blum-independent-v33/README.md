# Независимая заводская выгрузка 71T6650

Источник — DWG Démos, исходный файл и семь извлечённых бинарных потоков находятся в `inputs/supplier-cad/`. Все семь тел и 431 грань перенесены; исходные внутренние перекрытия не удалены.

- `blum-71t6650-*.step`, `factory-*.npz`: геометрия в исходных координатах DWG.
- `explicit-conversion.json`: сохранность граней, численные допуски соединения и исправления UV-обходов без изменения 3D-рёбер.
- `source-ray-check.json`: независимая численная проверка перекрытия 2/4 по исходным контурам, 4097 точек на кривую. `source-ray-check-coarse.json` — сравнение на 1025 точках; классификация всех девяти свидетелей совпала.
- `canonical/`: те же тела после единого жёсткого поворота по монтажной плоскости. Здесь также находится ранее полученная отдельная модель планки 175H7190 и номинальные шурупы.
- `diagnostic-before-alignment.json`: диагностическое паразитное пересечение до выравнивания системы координат. Это не текущая проверка узла.
- `canonical/diagnostic-v32-relief-fit.json`: промежуточная проверка с прежней выборкой глубиной 3,2 мм. Она выявила слишком маленький технологический зазор.

**Текущие деревянные детали, выборки 11 × 28 × 6, протокол 681 положения и комплект заказа находятся в [v33 узла](../cambusa-v33-independent-hinge/README.md).** Эта папка содержит источник и его перенос, а не альтернативные карты раскроя.
