## Где искать

- [work/](work/) содержит редактируемые Python, JavaScript, HTML, исходные JSON и исследования.
- [outputs/](outputs/) содержит исторические GLB, STL, OpenSCAD, DXF, карты листов, чертежи и отчёты.
- [previews/](previews/) содержит сохранённые интерактивные виды.
- [Манифест](manifest.json) перечисляет файлы снимка и контрольные суммы SHA-256.

Старые скрипты могут ссылаться на зависимости той итерации, браузерный рантайм и файлы в `input-materials/`. Они сохранены для чтения и воспроизведения с соответствующими входами. Для `render_reference_designs.py` распакуйте `work/reference-design-meshes.json.gz` в `work/reference-design-meshes.json`. Актуальная сборка v16 запускается из корня репозитория через `scripts/build.py`.

Присланные фотографии собраны в [фотогалерее](../references/photos/README.md). Для отдельных файлов CAD поставщиков указаны [ссылки на источники](../references/README.md).
