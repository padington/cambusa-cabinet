# Проверки перед следующим этапом

Это перечень ожидаемых свидетельств. Галочка без результата проверки и версии файла не считается доказательством. Неприменимость должна иметь объяснение.

| Область | Что должно быть в результате |
|---|---|
| Задание | Размеры и ограничения, нагрузки или явная неопределённость, регион, бюджет, домашние операции, выбранный вариант |
| Совместимость | Точный артикул/исполнение каждого участника системы, реальные размеры, комплектность, источники и противоречия |
| Каждое соединение | ID соединяемых деталей, крепёж в нужном месте, опирание/зацепление, отверстия и доступ инструмента |
| Геометрия | Состав и позиции, статика, полный ход механизмов, минимальные зазоры, метод/шаг/границы проверки |
| Толерансы и регулировки | Рабочий зазор с учётом материала/финиша; какие сочетания ошибок и регулировок проверены, какие нет |
| Нагрузки | Определённый случай нагружения, прогиб/прочность и крепление опор; устойчивость и открытые подвижные части, если есть |
| Обработка | Одна версия с моделью; базы/стороны/оси/координаты/диаметры/глубины/радиусы/допуски; зеркальные виды и торцы |
| Обратное чтение | Фактический экспорт совпадает по ID, составу, габаритам, позиции и критическим посадкам; просмотрщик не показывает старый вариант |
| Заготовки | Все экземпляры на целых листах/хлыстах, толщины, припуски, пропил, поля, направление волокон, ограничения поворота |
| Смета | Количество установленное и покупаемое, упаковки, запас, обработка, отделка и доставка; неизвестное отдельно; нет задвоения комплектов |
| Монтаж | Можно завести детали и гайки, установить последнюю стенку, подойти инструментом, снять обслуживаемое; дома не нужна запрещённая обработка |
| Изготовитель | Подтверждены фактические толщины, финиш, форматы задания и принимаемые допуски; замены согласованы |
| Приёмка | План измерений, пробной сборки, проверки механизма и согласованных нагрузок; зафиксировано, что уже проверено физически |
| Версия | Снимок параметров/исходников/источников/результатов, хеши и история изменений; воспроизводимая команда или инструкция пересборки |

Готовность ведётся **по узлам и по предмету целиком**. Если петля прошла CAD, но полки и устойчивость нет, статус целого не повышается автоматически. Для сложного нового соединения можно сначала выпустить заказ образца; это отдельный объём заказа с явно указанной целью проверки.

Физическая приёмка выполняется после получения деталей. Промпт и CAD не могут объявить её выполненной заранее. Для подтверждённого расчёта или документации производителя фиксируется именно это свидетельство и его применимость; не требуется притворяться, что каждый покупной винт испытан самостоятельно.
