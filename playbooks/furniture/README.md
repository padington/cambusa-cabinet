# Повторяемое проектирование мебели

**[Стартовый промпт v1.0](prompt.md)** · [вводные](brief.md) · [проверки перед выпуском](checks.md) · [скачать комплект ZIP](../../outputs/furniture-prompt-v1.0/furniture-prompt-v1.0.zip).

Задача — спроектировать мебель как комплект готовых деталей, который человек заказывает и собирает доступным инструментом. Промпт подходит для нового предмета и продолжения существующего проекта. Материалы, размеры, бренды и регион берутся из задания; Cambusa служит источником опыта.

## Как начать новый чат

1. Скопируйте весь текст prompt.md в новый чат.
2. Под заголовком «Вводные пользователя» добавьте описание. При необходимости используйте brief.md; заполнять все поля заранее необязательно.
3. Для продолжения проекта приложите актуальную модель/источники, версию, журнал решений и TODO. Сама ссылка на старый чат не заменяет его доступное содержание.
4. Назовите результат текущего захода: сравнить конструкции, проверить узел, выпустить присадку или собрать комплект для заказа.

Нужны инструменты, соответствующие результату: поиск для актуальных поставок, CAD и вычисления для геометрии, файлы и просмотр для выпуска артефактов. Промпт задаёт работу; сам по себе он не добавляет эти возможности модели и не выполняет физические испытания.

В последних ответах сохранены границы готовности Cambusa и предложены две схемы нового стеллажа. [Ответы и оценка](../../reports/furniture-prompt-evals/README.md). v1.0 — выпуск того же текста v0.3 с изменённым только заголовком версии.

Это ограниченная проверка первого ответа. Четыре граничных задания пока не запускались; полный инструментальный цикл проектирования и физическая сборка не проверены. Оценку проводила автор промпта, без слепого сравнения. Известный недочёт: ответы остаются развёрнутыми, несмотря на инструкцию сократить повторение вводных.

Это переносимые инструкции, а не установленный скилл или запущенная автоматизация. Без отдельного поручения новые интеграции, расписания и покупки не создаются.

## Пересобрать комплект

`python playbooks/furniture/package.py` собирает самостоятельный ZIP из промпта, вводных, проверок и сведений о выпуске. Зависимости — стандартная библиотека Python. Можно задать `--output` с другой папкой. Архив проверяется чтением обратно; отличающийся существующий выпуск не перезаписывается, для изменения нужен новый номер версии.
