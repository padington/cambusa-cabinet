# Замечания и исправления v30

Первые три изображения предоставлены пользователем в этом чате; они сохранены файлами, чтобы источник замечаний не зависел от временных путей вложений.

| Замечание | До исправления | После исправления |
|---|---|---|
| Лишнее отверстие в узле 18 мм | [Снимок пользователя](mount-before.png) | [Разрез с номерами деталей](mount-after.png) |
| Полки выступают за боковины | [Снимок пользователя](shelves-before.png) | [Полки внутри габарита, в каркасе](shelves-after.png) |
| Крепёж без отображаемых опор | [Снимок пользователя](unsupported-fasteners-before.png) | [Вид с верхней и нижней балками](shelves-after.png) |
| Регулировка левой двери | — | [Проверочная петля на 110°](hinge-after.png) |
| Пыль через пегборд | — | [Разрез глухого гнезда и пример штыря](pegboard-after.png) |

Снимки «после» получены из обновлённого просмотра v30. Переключение видов и открывание проверяет [браузерный сценарий](../../work/check-v30-viewer.cjs); он принимает путь к отдельной странице предпросмотра, создаваемой из фрагмента просмотра. Playwright должен быть доступен среде Node.js.

Размеры, состав исходных CAD и границы проверки приведены в [отчёте](../../outputs/cambusa-v30-review-fixes/IMPROVEMENTS.md). Изображения не заменяют производственные файлы и не означают проверки нагрузки.
